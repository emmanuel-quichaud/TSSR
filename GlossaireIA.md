# Glossaire

- **Agent** : système qui observe son environnement, choisit des actions et les exécute pour atteindre un objectif précis de façon autonome.  

- **Algorithme** : suite d’instructions ou de règles permettant de résoudre un problème ou d’effectuer une tâche.  

- **Alignement** : démarche visant à faire correspondre le comportement d’une IA aux intentions et aux objectifs humains.  

- **API** : (Application Programming Interface / Interface de programmation d'application)interface logicielle qui permet à deux programmes ou services informatiques de communiquer et d'échanger des données entre eux

- **Apprentissage** : processus par lequel un modèle ajuste son fonctionnement à partir de données ou d’exemples.  
Cf : 
- Machine Learning (ML)
- Deep Learning 
- Appentisssage supervisé / non supervisé


- **Auto-apprentissage** : capacité d’un système à apprendre à partir de données ou de retours avec peu d’intervention humaine.
- **Automatisation** : exécution d’une tâche par un logiciel ou une machine avec peu ou pas d’intervention humaine.
- **Autonomie** : capacité d’un système à fonctionner ou à prendre des décisions sans intervention humaine constante.
- **Base de données** : ensemble organisé d’informations pouvant être consultées, modifiées et gérées.
- **Bulle IA** : situation où les investissements et les attentes autour de l’intelligence artificielle risquent de dépasser sa valeur ou ses résultats réels.
- **Capacité** : aptitude d’un modèle ou d’un système à accomplir une tâche.
- **CUDA** : plateforme logicielle de NVIDIA permettant d’utiliser des GPU compatibles pour effectuer des calculs parallèles.
- **Cyberattaque par IA** : attaque informatique dans laquelle l’intelligence artificielle aide à automatiser ou à améliorer certaines opérations.
- **Danger** : situation ou élément susceptible de provoquer un dommage.
- **Distillation** : technique d’entraînement dans laquelle un modèle plus petit apprend à reproduire une partie du comportement d’un modèle plus grand.
- **Écoute** : en réseau, attente de connexions ou de messages sur une interface ou un port ; en IA vocale, capture ou analyse de l’audio.
- **Environnement** : contexte dans lequel un programme ou un agent fonctionne, comprenant notamment le système, les données et les outils accessibles.
- **Frontière (modèle)** : limite des capacités d’un modèle ; l’expression « modèle de frontière » désigne généralement un modèle d’IA parmi les plus avancés.
- **Génératif** : capable de produire du contenu, par exemple du texte, des images, du son ou du code.
- **Gouvernance** : règles, responsabilités et contrôles encadrant le développement et l’utilisation d’un système.
- **GPU** : processeur conçu pour effectuer de nombreux calculs en parallèle, utilisé notamment pour l’IA.
- **Hallucination** : réponse d’une IA qui semble plausible, mais contient une information fausse ou inventée.
- **Harnais** : ensemble de composants qui encadrent un modèle et gèrent ses consignes, ses outils, son exécution et ses contrôles.
- **HuggingFace** : plateforme proposant des modèles, des jeux de données et des outils pour développer et utiliser des systèmes d’IA.
- **Inférence** : phase durant laquelle un modèle entraîné produit une réponse ou une prédiction à partir d’une entrée.
- **Injection** : dans le contexte de l’IA, consigne malveillante visant à détourner le comportement d’un modèle ou à lui faire ignorer ses instructions.
- **Invasif** : qui collecte des données, observe ou influence les personnes de manière intrusive.
- **Limite** : contrainte qui réduit les connaissances, les capacités ou les possibilités d’un système.
- **LLAMA** : famille de grands modèles de langage développée par Meta, généralement écrite « Llama ».
- **LLM** : grand modèle de langage entraîné sur de grandes quantités de données pour comprendre et générer du texte.
- **Machine Learning** : domaine de l’intelligence artificielle où les systèmes apprennent des régularités à partir de données.
- **Mathématique** : discipline qui étudie notamment les nombres, les structures et les relations, et fournit des méthodes fondamentales à l’IA.
- **Mémoire unifiée** : architecture mémoire permettant à plusieurs composants, comme le processeur et le GPU, de partager ou de coordonner l’accès à la mémoire.
- **NVIDIA** : entreprise technologique connue notamment pour ses GPU et ses plateformes de calcul utilisées en IA.
- **OpenClaw** : projet d’agent IA open source dont les fonctions précises dépendent de sa version et de sa documentation.
- **OpenRouter** : service proposant une API commune pour accéder à différents modèles d’intelligence artificielle.
- **Paramètre** : valeur qui influence le fonctionnement d’un modèle ; dans un réseau neuronal, elle est généralement apprise pendant l’entraînement.
- **Poids** : paramètre numérique appris par un réseau neuronal qui détermine l’influence des informations dans ses calculs.
- **Pre-trained** : qualifie un modèle qui a déjà été entraîné sur un ensemble de données avant d’être utilisé ou adapté à une tâche.
- **Prompt** : instruction ou ensemble d’informations fourni à un modèle pour orienter sa réponse ou son action.
- **RAM (DRAM)** : mémoire vive qui conserve temporairement les données et programmes en cours d’utilisation ; la DRAM est un type courant de RAM.
- **RAG** : méthode permettant à un modèle de rechercher des informations dans des sources externes et de les utiliser pour produire une réponse.
- **Réseau neuronal** : modèle informatique composé de couches de calcul reliées entre elles et entraîné à reconnaître des régularités dans les données.
- **Robotisation** : utilisation de robots physiques ou logiciels pour effectuer des tâches.
- **SLOP** : terme péjoratif désignant du contenu numérique généré en masse, souvent par IA, de faible qualité ou répétitif.
- **Singularité technologique** : hypothèse selon laquelle un progrès technologique, notamment lié à l’IA, pourrait devenir si rapide qu’il serait difficile d’en prévoir les conséquences.
- **Souveraineté** : capacité à garder le contrôle de ses données, de ses infrastructures et de ses choix technologiques.
- **Super intelligence** : intelligence hypothétique qui dépasserait largement les capacités humaines dans la plupart des domaines cognitifs.
- **Token** : unité de texte traitée par un modèle de langage ; elle peut correspondre à un mot, à une partie de mot ou à un signe.
- **TPU** : processeur spécialisé développé par Google pour accélérer certains calculs d’apprentissage automatique.
- **Transformer** : architecture de réseau neuronal utilisant notamment un mécanisme d’attention pour traiter les relations entre les éléments d’une entrée.
- **Vérification** : contrôle visant à déterminer si une information, une réponse ou une action est correcte.
- **Wikipedia** : encyclopédie collaborative en ligne dont les articles sont rédigés et modifiés par des bénévoles.
